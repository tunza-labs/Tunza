This is the idea, not proof. There is no trained model yet, no dataset, and no permission to use Kenya's health records.

Someone is sick and care is far. A person has to decide what happens next. The idea is that the next step is obvious: go now, get care today, watch at home, or ask one more question. If the system is wrong, it should send the person for care, not wave them off.

This is not a chatbot doctor, and it is not a replacement for the national health record. The screen already has careful rules in English and Swahili. A model, if one is built, would only be allowed to raise the urgency, never lower it. It would read messy notes those rules miss, and ask the next question. Connecting to Kenya's community health system is not permission to train on that data.

Building it does not mean training a model from scratch. It means start from the decision: who should be seen first when a clinic can only see so many people. Day one is the rules already on the screen. Later, a strong existing model would get a small add-on and be checked on locked tests. That has not been done.

There is no data yet. A partnership would be how data gets in. Outcomes would come back from the health worker and the household. That set of outcomes does not exist. Before any training, a person still has to name what the model is predicting, which product it serves, a clinician has to sign the rules, there has to be a note that the data may be used, and a test set has to be locked before any training. None of that is signed.
